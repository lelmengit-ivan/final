## 🔧 Troubleshooting

### Server Won't Start
```bash
# Make sure port 5000 is free
# Or change port in app.py (last line)
```

### Can't Login
- Use: `admin` / `admin123`
- Or register a new account
- Check caps lock is off

### No Data Showing
- Make sure you ran `python seed_data.py`
- Check database file exists: `pharmacy.db`

### Charts Not Loading
- Ensure internet connection (Chart.js from CDN)
- Refresh the page
- Check browser console for errors
